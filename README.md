# 🚀 TechNews Today — Portal de Tecnologia

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)

Um portal moderno e responsivo sobre notícias do mundo da tecnologia, desenvolvido com **HTML5** e **CSS3** recorrendo a técnicas visuais como *Glassmorphism*, *CSS Grid* e *Flexbox*.

---

## 📌 Funcionalidades

- **Layout Moderno (Dark Mode):** Interface escura estilizada com tons azuis e gradientes.
- **Header Sticky com Glassmorphism:** Barra superior translúcida que permanece fixa durante a navegação.
- **Artigo Interativo:** Notícia em destaque com elemento expandível `<details>` para revelar mais conteúdo.
- **Secção Multimédia:** Leitor de vídeo do YouTube incorporado com moldura personalizada.
- **Formulário de Newsletter:** Área de subscrição com seleção de tópicos de interesse e caixa de aceitação de termos.
- **Design Responsivo:** Grelha adaptável para ecrãs de telemóvel e computador (`@media (min-width: 768px)`).
